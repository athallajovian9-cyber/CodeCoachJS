# 🚀 CodeCoach JavaScript (JS)

> **Kid-Friendly, Approaches JavaScript Coding for Young Coders & Beginners!**

CodeCoach JavaScript turns tricky JavaScript bugs, runaway browser loops, and confusing scope rules into fun, easy-to-understand learning moments.

---

## 🌟 Features
- **Kid-Friendly Diagnostic Engine**:
  - `QUIET BUG`: Catches single `=` assignment inside `if` statements before it breaks your game.
  - `LOOP NEVER STOPS!`: Warns about runaway `while (true)` loops that freeze web browsers.
  - `TRICKY PITFALL`: Catches loose `==` equality and teaches strict `===`.
  - `OUTDATED HABIT`: Flags legacy `var` and promotes modern `let` & `const`.
  - `NaN EQUALITY TRAP`: Prevents `x === NaN` bugs.
- **Interactive Desktop GUI (`START_GUI.bat`)**:
  - Dark-mode side-by-side editor with real-time feedback.
  - 1-click Discord Community access (`💎 First 100 Badge`).
- **Interactive Quiz & Reward Game (`RANDOM_QUESTION.bat`)**:
  - Random beginner challenges with unlockable badges and trophies.
- **Adult / Educator Diagnostic Mode**:
  - Run with `--parent` for formal technical reports.

---

## 🚀 Quick Start
```bash
# 1. Launch the Desktop GUI
START_GUI.bat

# 2. Or play the Challenge Question Quiz
RANDOM_QUESTION.bat
```
